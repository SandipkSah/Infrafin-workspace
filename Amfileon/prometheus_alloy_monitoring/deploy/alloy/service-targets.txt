# ClickHouse, Redis and GitLab instances that Alloy collects metrics from.
# Edit this file, then run `python3 gen_services.py` (writes hosts/<host>.services.alloy,
# hosts/<host>.compose.yaml and hosts/<host>.redis-list) and stage Alloy on that host.
#
# Scope (decided 2026-10-28): production + staging of Amfileon's own services. Not included: dev
# clusters, the plain "clickhouse" projects (db1/cpu1/gpu1), app-internal Redis/ClickHouse
# (sentry, netbox, zulip, infisical, conda) — add a line here to include one.
#
# Columns:
#   host     where the instance runs (its Alloy collects it)
#   kind     clickhouse | redis | gitlab
#   name     container name (also the instance label: clickhouse=… / redis=…)
#   cluster  label used by the dashboards' Cluster drop-down
#   role     clickhouse: server|keeper (label role) · redis: server|sentinel (label kind) ·
#            gitlab: puma|workhorse|sidekiq|exporter (job gitlab-<role>)
#   address  clickhouse/gitlab: <container>:<port> over a Docker network (port is NOT published)
#            redis: <host LAN IP>:<published port> (already published today) + container port after "/";
#                   TLS-only instances: rediss://<name on its certificate>:<port>/<container port> — Alloy
#                   resolves that name to this host (extra_hosts) and verifies it against the Amfileon CA.
#                   Names checked 2026-10-28: production.redis.amf (production cert, DNS → prod3), redis.amf
#                   and db1/prod3.redis.amf (staging/redis:8 cert). db1's override of production.redis.amf is
#                   why that name's certificate check runs on prod3 (certificate-targets.txt).
#   network  Docker network Alloy joins to reach the container ("-" = none, "?"/"host?" = can't be reached yet)
#   on       on = collected · off = prepared, not collected yet (see deploy/services/INSTALL.md)
#
# host  kind        name                                                 cluster                role       address                                                   network                                   on
